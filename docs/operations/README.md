# Operations

Maintained instructions for the current local system.

| Task | Guide |
|---|---|
| Install dependencies, run services, sign in to ESPN, and test | [Run locally](run-local.md) |
| Capture the latest completed week and publish observation tables | [Refresh data](refresh-data.md) |
| Build, publish, and query observation tables | [Observation tables](tables.md) |
| Fetch source inputs and existing research releases | [Shared research data](shared-data.md) |
| Download, verify, and read tracking source releases | [Tracking data](tracking-data.md) |
| Build and query dated player roster, transaction, and injury evidence from 2002 | [Historical availability](availability-history.md) |
| Launch notebooks or reproduce archived experiments | [Research workflows](research-workflows.md) |
| Install NVIDIA tree libraries and benchmark local RB fits | [GPU research setup](gpu_research_setup.md) |
| Train, evaluate, publish, and query ChairStats campaign bundles | [Model campaigns](model-campaigns.md) |
| Work on frontend routes, queries, and browser checks | [Frontend guide](../../web/README.md) |

There is no selected analytical release. The published table catalog is
`data/tables/current.json`; every campaign bundle under `data/campaigns/` is
queryable through the API. Dated release notes are evidence of previous changes.
See the [documentation index](../README.md) for architecture and future work.
